# Content review checklist

- Verify each official objective and descriptive statement against the retrieved source version; retain exact wording and stable IDs.
- Separate framework wording, current Massachusetts policy, endorsement competencies and teacher indicators.
- Record URL, actual retrieval time, content hash, supporting excerpt, source version and review state. Retrieval date is not an effective date.
- For each authored check, verify the answer key, explain the distractors, examine counterexamples, and identify ambiguous accepted variants. Unrecognized short answers enter review.
- Confirm there is no invented monitoring duration, threshold, accommodation entitlement, raw-score cutoff, or personal pass prediction.
- Confirm task families and unfamiliar tags describe actual item differences. Rephrasing is not independent evidence.
- Label all custom five-part prompts as derived practice. The public sample exposes Part I; do not invent official Parts II–V.
- Verify mentor text/version/hash and rubric reference across all five parts.
- Record model review as model review. Source comparison is not human review; only a real human action can grant human_reviewed.
- Before wider use, a qualified educator should review all seed keys, legal qualifications, mappings and rubric interpretations. No such human validation is claimed in this build.
